[Zero-UUID Version Bit Bypass]: Fixed zero-UUIDs (00000000-...-0001) fail standard UUIDv4 version bit checks; schema validation must explicitly permit non-v4 shapes solely for stage-one stubs while enforcing strict v4 generation in production signers.

[Glob-Anchor Root Evasion]: Standard glob matchers miss root-level hidden files (.env, .git) unless checks explicitly evaluate both normalized paths and ./-prefixed variants against **/ patterns.

[TOCTOU Closure via dir_fd, Not Path Strings]: A lexical `Path.resolve()` containment check is stale the instant it returns; only re-resolving by path string at open-time reintroduces the race. Closing it requires a `dir_fd`-based walk (`os.open(part, O_NOFOLLOW, dir_fd=parent_fd)` per component) so the kernel atomically rejects a symlink swapped in after authorization. `os.supports_dir_fd` gates this to Linux/macOS; Windows has no equivalent and must keep a documented, honestly-labeled fallback.

[O_NOFOLLOW+O_DIRECTORY Raises ENOTDIR, Not ELOOP, on Linux]: Reading the open(2) man page's O_NOFOLLOW section is not a substitute for an empirical check of the exact flag combination in use. On real Linux, `os.open(part, O_DIRECTORY|O_NOFOLLOW, dir_fd=parent_fd)` against a symlinked intermediate directory raises `NotADirectoryError`/`ENOTDIR`, not `ELOOP` -- confirmed by running it, after a prior ELOOP-only assumption (based on man-page reading alone) caused a real test failure on Linux while passing on Windows. Any errno-based symlink/TOCTOU check must catch both `errno.ELOOP` and `errno.ENOTDIR` and should be verified by actually running on the target kernel, not just by reading documentation.

[A Test's Skip Reason Can Be a Lie]: `_try_symlink()`'s test helper only handled replacing an existing symlink or regular file (`Path.unlink()`); called against an existing real directory it raised `IsADirectoryError`, was swallowed by a broad `except OSError: return False`, and the caller reported "symlink creation is not permitted in this environment" -- 100% misattributed to environment/privilege, on every platform, hiding a genuine gap in write-side TOCTOU test coverage. Always verify a skip's *actual* underlying exception before trusting its stated reason.

[SQLite Mixed Timestamp Formats Break String Comparison]: A table whose `created_at` DEFAULT uses `strftime('%Y-%m-%dT%H:%M:%fZ','now')` (fractional seconds) alongside application code writing `isoformat(timespec="seconds")` (no fractional seconds) cannot be safely compared/ordered via raw SQL string comparison -- two timestamps in the same second can sort backwards. Parse both to `datetime` in Python before comparing.

[Retention Sweeps Must Exclude Live-Serving Rows]: A cleanup/expiry sweep over a table that also backs a "latest active" read path (e.g. `latest_approved()`) must hard-exclude the status value that path depends on (e.g. `status != 'approved'`), not just filter by age -- age-only filtering will eventually delete the one row still being served.

[Background Lifespan Tasks: Sleep First, Not After]: A lifespan-scoped `asyncio.create_task` background loop should `await asyncio.sleep(interval)` *before* its first unit of work, not after. Tests that create the app and tear it down without yielding control between task creation and cancellation never let the task run at all, so first-sleep is what keeps such tests safe by construction rather than by accident.

[Asymmetric Sigstore Fallback Risk]: Production-to-local fallback mechanisms (e.g., Sigstore failing over to Ed25519) require explicit permission hardening (chmod 0600) on auto-generated keys to prevent silent local privilege vulnerabilities.
